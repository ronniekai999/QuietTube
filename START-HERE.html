QuietTube

A small companion for your everyday browser.

Get connected on Windows

  1. Extract the entire QuietTube ZIP, then double-click Setup.cmd.
  2. In Edge, open edge://extensions. Turn on Developer mode, choose Load unpacked, and select the installed extension folder shown by setup.
  3. Pin QuietTube to the toolbar. Open its popup and check for Windows app connected.
  4. Reload YouTube and play a video. The tray app should show that Edge has confirmed the current protection setting.

For Chrome, use chrome://extensions and the same installed extension folder.

If ads or a playback warning appear

Reload the video after changing protection. Check that QuietTube is enabled and its YouTube site access is allowed. If another ad blocker is active, temporarily disable it for YouTube while testing QuietTube.

YouTube can change its player or blocking detection. The first build uses packaged uBlock Origin Lite filters; fixes that change scripts require a new QuietTube extension package. This test build does not download or execute remote JavaScript.

Use Export diagnostics in the Windows app and record which browser and video reproduced the problem. Diagnostics contain connection and filtering settings, without browsing history, account cookies, or video URLs.

What the controls do

Turn off stops QuietTube filtering. Pause 15 minutes resumes automatically. With the Windows companion connected, controls synchronize across connected browser profiles. Reload an already open video after changing protection.

Closing the tray window keeps the background app running. Quitting the tray app leaves the extension filtering with its saved settings.

Updates and removal

For this private test build, replace the installed files by running setup from a newer ZIP, then reload QuietTube on the browser’s Extensions page. Your protection settings are preserved.

To remove it, remove the extension in each browser, then run Uninstall.cmd from the ZIP. Uninstall removes only QuietTube’s per-user app files, native messaging registrations, shortcut, and startup entry.

QuietTube uses uBlock Origin Lite’s open-source filtering engine. QuietTube is an independent modification, and is not an official uBlock Origin release. The engine being active is not a guarantee that every YouTube ad will be blocked.
